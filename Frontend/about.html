Our Story

Built to make practice actually work

QuizCraft started as an MCA final year project with a simple idea: quizzes should adapt to the learner, not the other way around.

Our Mission

To make focused, adaptive practice a five-minute daily habit for every student — regardless of their starting level.

Our Vision

A learning platform where difficulty, pacing and feedback are all personalized in real time, for every subject a student studies.

Why Adaptive?

Fixed-difficulty quizzes waste time on questions students have already mastered — or overwhelm them too early. Adaptive practice fixes both.

How It's Built

Development Workflow

01
UI/UX Design

Every screen starts as a design-system-first layout — consistent colors, spacing and components across all pages.

02
Frontend Build

HTML5, CSS3, Bootstrap 5 and vanilla JavaScript power every page, with Chart.js for analytics and AOS for scroll animation.

03
API Integration

Django REST Framework will expose endpoints for authentication, questions, quiz attempts and results.

04
Database Layer

MongoDB stores question banks, student profiles and quiz history behind the Django API layer.

05
Adaptive Engine

A difficulty-adjustment algorithm reads each student's running accuracy and reshapes the next question set.

06
Testing & Deployment

End-to-end testing across devices, followed by deployment as a complete MCA final year project submission.
